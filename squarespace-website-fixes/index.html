Squarespace website fixes in Lawrence, MA

I fix Squarespace sites that look wrong on phones, have sections that won't line up, or have forms that don't reach you. I work inside your current site, so you keep your template, your domain and your plan. I'm based in Lawrence, MA and work remotely anywhere.

What's included.

I've rebuilt sections, galleries, accordions and a shop page on a live Squarespace 7.1 site, including custom CSS for the mobile layout.

  • Mobile layout: spacing, stacked blocks, and text that's too big or too small
  • Fonts, colors and buttons that don't match across pages
  • Galleries, accordions and Fluid Engine section layouts
  • Custom CSS and code injection for things the style panel can't do
  • Forms tested, so requests reach the right inbox
  • Store pages and product blocks that won't add to cart

Who it's for.

Owners who built their site on Squarespace 7.0 or 7.1, want to keep editing it themselves, and need a few things fixed rather than a whole new website.

Honest limits.

  • This keeps you on Squarespace. I don't work on Wix or WordPress sites. If you'd rather move off Squarespace, that's a new website project.
  • Some code features need a higher Squarespace plan. If yours doesn't have them, I tell you before I start.
  • One fix is one problem on one page. If you're unsure how many you have, send the list and I'll count it first.

How it works.

  1. Send the list

    Your site link and a list of what bugs you. Screenshots help. I count the fixes before we agree on anything.

  2. Invite me as a contributor

    You invite me under Settings > Permissions, and I tell you which permission the fix needs. No password needed.

  3. Fix, test, list

    I save your current custom CSS, make the fixes, test the changed pages on a phone and a desktop, and list every change so anything can be undone.

Common questions.

Do you need my password?

No. Invite me as a contributor under Settings > Permissions. I tell you which permission the fix needs, and you can remove me when I'm done.

Will this break my template?

I save a copy of your current custom CSS before I start and list every change, so anything can be undone.

What counts as one fix?

One problem on one page, like “the gallery stacks wrong on phones” or “the button color doesn't match.” If you're unsure, send the list and I'll count it first.

Can you move my site off Squarespace?

Yes, as a new website project. This service keeps you on Squarespace.

Do you work on Wix or WordPress?

Not for fixes like these. I work on Squarespace sites, and I build new sites in code.

What it costs.

Small fixes are done as consulting at $75 an hour, with the scope and an estimated time agreed first. Want someone keeping the site current every month? Monthly website support starts at $150 a month.
